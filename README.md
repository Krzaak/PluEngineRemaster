
# PluEngine

Simple 3D OpenGL game engine written in C++ with Python as a scripting language.


## Tech Stack

**Engine:** 
OpenGL, 
[Jolt Physics](https://github.com/jrouwe/JoltPhysics), 
C++, 
[spdlog](https://github.com/gabime/spdlog), 
[ImGui](https://github.com/ocornut/imgui)

**Scripting:** Python
